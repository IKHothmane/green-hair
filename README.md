# Green Hair Sevilla — sitio web

Sitio web animado para **Green Hair Sevilla**, peluquería ecológica y partner oficial Aveda en el Casco Antiguo.

## Datos públicos

- **Dirección:** C. Francos, 14, Loc 3, Casco Antiguo, 41004 Sevilla
- **Teléfono:** +34 954 10 40 49
- **Mapa:** [Google Maps](https://www.google.com/maps?q=Green+Hair+Sevilla,+C.+Francos,+14,+Loc+3,+Casco+Antiguo,+41004+Sevilla)
- **Horario publicado (fuentes públicas):**
  - Lunes: 14:00–18:30
  - Martes–viernes: 09:30–18:30
  - Sábado: 09:00–13:00
  - Domingo: cerrado

Confirma horarios con el salón antes de publicar.

## Stack

- React + Vite
- GSAP + ScrollTrigger
- Contenido ES / EN / FR
- Fotos reales del salón (Google Maps / AlCentro)

## Arranque

```bash
cd D:\green-hair-sevilla
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
